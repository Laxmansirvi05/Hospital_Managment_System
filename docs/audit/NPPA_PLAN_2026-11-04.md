## Official source findings

- NPPA says its [proactive disclosure page](https://nppa.gov.in/en/proactivedisclosure) lists ceiling prices for 935 formulations as of 2026-06-23 and says prices are revised annually using Wholesale Price Index. The same official source says ceiling prices are for specified scheduled formulations. This does not establish a machine-readable dataset or a matching API.
- The NPPA [therapeutic-category ceiling-price page](https://www.nppa.gov.in/en/therapeuticcategorywiseceilingpricelist) links category-specific documents. Official NPPA notification PDFs expose formulation/composition, pack description, brand, company, strength, pack size, unit, and price fields in examples, but those documents are not yet proven to be the intended data.gov.in resource.
- The official [Pharma Sahi Daam page](https://nppa.gov.in/en/pharma_sahi_daam) describes an NPPA search tool for medicine prices. No public API endpoint or terms for automated extraction were verified from that page.
- The data.gov.in [OGD catalog](https://www.data.gov.in/catalogs/) says resource owners control the content and published datasets/resources are licensed under the Government Open Data License-India. The [license](https://data.gov.in/Godl) requires provider/source/license attribution, prohibits suggesting provider endorsement, disclaims warranty, and does not guarantee continuity of updates. Verify the license metadata on the exact resource before reuse.
- The data.gov.in [Help page](https://data.gov.in/help) describes API key generation and API URL access for registered users. It does not establish this dataset's endpoint or quota. India OGD rate limits, quota, and response size are **UNKNOWN**. Do not apply US data.gov/API limits to India's portal.
- The resource-specific terms and robots rules are **UNKNOWN** because no exact resource URL was identified. The `robots.txt` URL could not be fetched by the browser research tool. An API key does not itself grant permission to reuse data beyond its resource license.
